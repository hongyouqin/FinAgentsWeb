## 二、方法一：财报逐项解读

### 2.1 使用场景

每年 4 月、8 月、10 月财报季，快速把年报/季报的关键段落翻译成投资视角的结论。

### 2.2 可复用 Prompt

```
你是一名 A 股资深基本面分析师。以下是 {公司名称} {报告期} 的财报节选：

{财报原文}

请按以下结构输出分析：

一、核心数据变化
- 营收：YoY / QoQ
- 净利润：YoY / QoQ
- 毛利率 / 净利率变化
- 经营性现金流 / 净利润比

二、异常信号（3 条以内）
（例如：应收账款大幅上升、存货周转天数拉长、商誉减值等）

三、管理层表述解读
（DEI 部分的关键措辞 + 你的翻译）

四、投资结论
- 短期（3 个月）：看多 / 看平 / 看空
- 长期（1 年以上）：看多 / 看平 / 看空
- 核心逻辑（不超过 100 字）
```

### 2.3 输出示例

以某消费龙头 2025 年三季报为例，Qwen 的输出摘录：

> **异常信号**：应收账款同比增长 42%，显著高于营收增速 18%，可能存在渠道压货或账期放宽，需要结合经销商动销数据进一步判断。

这种「基于数据的异常识别 + 后续验证建议」正是大模型相对量化模型的优势所在。

## 三、方法二：同行估值横向对比

### 3.1 使用场景

判断某只股票当前估值是便宜还是贵，最有效的方法是横向对比同业。

### 3.2 可复用 Prompt

```
请对以下 {N} 家同行业上市公司的估值进行横向对比：

{公司列表及关键指标表格}

分析维度：
1. PE / PB / PS / EV-EBITDA 分位数（在自身历史 5 年区间的位置）
2. 相对同行溢价 / 折价（溢价为正，折价为负）
3. 溢价 / 折价是否合理（结合基本面差异）
4. 按综合性价比排序

输出表格 + 一段结论（不超过 200 字）。
```

### 3.3 使用技巧

- 一次对比 3–5 家足够，过多会稀释分析深度
- 基本面差异（成长性、ROE、护城河）要明确写在 prompt 里，避免模型纯看估值数字
- 同一个 prompt 在不同模型上跑一遍做交叉验证

## 四、方法三：事件驱动分析（消息面）

### 4.1 使用场景

出现重大政策、业绩预告、管理层变动、并购重组等事件时，需要快速评估影响。

### 4.2 可复用 Prompt

```
以下是 {股票名称} 近 {N} 天的公告、新闻与券商研报节选：

{素材列表}

请分析：

一、事件分类
- 利好事件（列出 + 影响程度：大 / 中 / 小）
- 利空事件
- 中性事件

二、综合情绪打分（-1 到 1，-1 极度悲观，1 极度乐观）

三、预期冲击路径
- 短期（1-5 个交易日）：股价预期波动区间 + 方向
- 中期（1-3 个月）：基本面影响程度
- 长期（1 年以上）：逻辑是否改变

四、需要跟踪的后续信号（3 条）
```
