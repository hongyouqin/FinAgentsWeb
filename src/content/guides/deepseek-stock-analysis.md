### 2.2 分析流程

DeepSeek 在 TradingAgents 中扮演「分析师 + 研究员」角色，整体流程如下：

1. **数据采集**：每日抓取目标股票的行情、公告、新闻、券商评级
2. **基本面分析**：DeepSeek 解读财报关键指标（ROE、毛利率、现金流）
3. **情绪分析**：DeepSeek 扫描相关新闻并给出情绪打分（-1 到 1）
4. **多空辩论**：两个 DeepSeek 实例分别扮演多头和空头，进行 3 轮辩论
5. **最终信号**：交易员角色综合输出买入 / 持有 / 卖出信号

### 3.2 DeepSeek 做得好的场景

- **财报解读**：对净利润变动原因、应收账款异常等能给出专业分析
- **事件驱动**：能识别政策利好、管理层变动等事件对股价的潜在影响
- **多空辩论**：双实例辩论显著降低单边偏见，提升信号质量

### 3.3 DeepSeek 的局限

- **短周期技术面**：对分钟级 K 线、量价关系不如专业量化模型
- **消息滞后**：依赖 API 抓取的新闻，实时性不如专业舆情系统
- **幻觉风险**：极个别案例出现"编造数据"，需要多源交叉验证

## 四、3 个可复用的 Prompt 模板

### 4.1 基本面快速诊断

```
你是一名资深 A 股基本面分析师。请基于以下数据对 {股票名称}({股票代码}) 进行基本面诊断：
{财报关键指标}
{行业对比数据}

输出格式：
1. 核心优势（3 条）
2. 主要风险（3 条）
3. 估值水平（低估 / 合理 / 高估，给理由）
4. 投资评级（强烈推荐 / 推荐 / 中性 / 回避）
```

### 4.2 事件驱动分析

```
以下是 {股票名称} 近 7 天的公告和新闻：
{新闻列表}

请分析：
1. 哪些事件对股价有利？影响程度（大 / 中 / 小）
2. 哪些事件对股价不利？影响程度
3. 综合情绪打分（-1 到 1）
4. 未来 5 个交易日的方向判断
```

### 4.3 多空辩论（双实例）

```
【多头角色】
作为 {股票名称} 的多头研究员，请列出支持买入的 5 个核心理由，并逐条反驳可能的空头论点。

【空头角色】
作为 {股票名称} 的空头研究员，请列出支持卖出的 5 个核心理由，并逐条反驳多头论点。
```
