# TET 三维量化指标：锚定趋势 + 情绪指数 + 择时信号，一套不被情绪绑架的 A 股择时框架

> TET = Trend · Emotion · Timing。它是一套把「趋势」和「情绪」**显式剥离**的三维量化指标体系——先在情绪最平稳的窗口锚定真实趋势（ATS），再独立计算短期情绪超买超卖（EI），两者相减得到择时信号（TI）。叠加一条「个股 vs 大盘」的联合趋势（JTS）后，一张图就能看清：这支股票现在处于什么位置、大盘是否在帮忙、该加仓、减仓还是观望。

## 一、散户最怕的不是"看不准"，是"看对了还做错"

几乎每个做 A 股的朋友都经历过这样的场景：

- 基本面看得很清楚，但一根巨阴把你吓了出来；
- 均线明明还没跌破，你却因为当天的弹幕和讨论区的"主力砸盘"恐慌割肉；
- 技术指标给出"金叉"，但其实是连涨 7 天后的强弩之末；
- 指数涨 3%，你股票跌 1%——你以为自己"跑输大盘"，其实是**行业轮动 + 情绪溢出**。

真正让交易失败的，往往不是方向错了，而是**把情绪当成了趋势**。所有经典的均线指标（MA、MACD、RSI、KDJ）都有一个共同缺陷：它们混淆了"价格中蕴含的趋势信息"与"价格中蕴含的情绪信息"——涨停当天 MA 上移，不代表趋势更强，可能只是短期情绪亢奋。

**TET 指标体系的设计目标，就是把这两样东西拆开看。**

## 二、TET 的三件套：ATS + EI + TI

### 2.1 Anchored-Trend-Score（ATS·锚定趋势）

**定义**：在情绪最平稳的交易日上，计算个股的真实趋势得分，值域 `[-1, 1]`。

**核心思路**：传统趋势指标在"行情情绪化"时会失真。ATS 反其道而行——**先识别出每一段行情中情绪波动最小的交易日（"锚定日"），只在锚定日的收盘价序列上做趋势拟合**，自然过滤掉暴涨暴跌的噪声。

| ATS 数值区间 | 业务含义 | 操作倾向 |
|---|---|---|
| `[0.5, 1.0]` | 强势上升 | 趋势稳健，回踩不破即加仓 |
| `(0, 0.5)` | 温和上升 | 持有，等量能共振 |
| `(-0.5, 0)` | 温和下行 | 观望，不做多 |
| `[-1.0, -0.5]` | 深度下行 | 远离，等待拐点 |
| `= 0` | 震荡盘整 | 箱体操作 |

**为什么比 MACD 更稳？**

> 同样一支涨停板，MACD 当天会给出一个非常强的 DIF 上穿信号，但 ATS 会把这一天识别为"非锚定日"而跳过，只在接下来情绪回归的交易日上继续拟合。**连涨 5 天再涨停**和**震荡 20 天后突然涨停**，ATS 会给出完全不同的解读。

### 2.2 Emotion-Index（EI·情绪指数）

**定义**：短期情绪与超买超卖程度，值域 `[-1, 1]`。

- `EI ≤ -0.3`：情绪低迷 / 深度超卖 —— 这通常是「别人恐惧我贪婪」的入场窗口
- `-0.3 < EI < 0.3`：情绪平稳 —— 最适合做决策、加减仓的窗口
- `EI ≥ 0.3`：情绪亢奋 / 超买区 —— 即便趋势仍强，也要警惕短期回调

**关键点**：EI 和 ATS **不共用数据源**。ATS 反映的是"价格做了什么"，EI 反映的是"市场对价格做这件事有多激动"。所以 EI 很强不等于趋势好，很弱也不等于要崩盘，它只是一个**情绪标尺**。

### 2.3 Timing-Indicator（TI·择时信号）

**公式**：

```
TI = ATS − EI
```

值域 `[-2, 2]`。设计意图是用一个减法，把"趋势向上 + 情绪未爆发"这种最理想的入场形态显式打分。

| TI 数值 | 市场形态 | 信号 |
|---|---|---|
| `TI ≥ 1.0` | 趋势强 + 情绪冷 / 趋势向上 + 情绪低迷 | **考虑做多**（理想窗口） |
| `0.5 ≤ TI < 1.0` | 偏多观察 | 关注、轻仓试错 |
| `−1.0 < TI < 0.5` | 未触发 | 观望 |
| `TI ≤ −1.0` | 趋势弱 + 情绪热（趋势下行但市场仍在亢奋） | **趋势不明**，**不作为做空依据** |

> ⚠️ 特别强调：`TI ≤ −1.0` 只是告诉你"趋势不明、该离场观望"，**不是做空信号**。A 股的散户账户不具备方便的做空工具，而且在"趋势弱 + 情绪热"的背景下继续下跌的概率并不高于反弹概率，这是 A 股市场特有的结构性事实。

### 2.4 四个指标对照速查

| 指标 | 问题 | 值域 | 理想区间 |
|---|---|---|---|
| ATS 锚定趋势 | 价格走什么趋势？（去噪后） | `[-1, 1]` | `> 0.5` |
| EI 情绪指数 | 市场对价格有多激动？ | `[-1, 1]` | `[-0.3, 0.3]` 平稳 |
| TI 择时信号 | 现在是不是进场的时候？ | `[-2, 2]` | `≥ 1.0` |
| JTS 联合趋势 | 大盘是在帮忙还是拖后腿？ | `[-1, 1]` | 越接近 `+1` 越好 |

## 三、JTS 联合趋势：把"大盘环境"加进来

光看个股是不够的。一支业绩不错、ATS 也向上的股票，如果大盘正在系统性下跌，你大概率还是会亏钱——这是 A 股所有老股民都反复验证过的"β 拖累"。

JTS（Joint Trend Score）就是把这件事定量化：

**判分机制**（三条规则，一图看懂）：

1. **同向同号 → 取两者更弱的一方打分**
   - 个股 ATS = 0.8，沪深 300 ATS = 0.3 → JTS = 0.3（大盘拉后腿，"强势"打折）
   - 个股 ATS = −0.9，沪深 300 ATS = −0.2 → JTS = −0.2（个股比大盘更惨，但按大盘的降幅记）
2. **方向相反 → 直接判 0 分**
   - 个股 ATS = 0.6，沪深 300 ATS = −0.5 → JTS = 0（方向背离，不给评分）
3. **越接近 `+1`，越理想**——个股顺着大盘涨势，且强于大盘。

**为什么这么设计？**

- **同向取弱**：尊重"木桶短板"——哪怕个股很强，大盘塌方时你也赚不到绝对收益。
- **反向判 0**：A 股的"方向背离"通常撑不过 2-3 周，与其硬给一个看起来刺激的分数，不如直接归零，提醒使用者"这是一个不稳定的结构"。

> **JTS = +1** 的样子：个股强趋势 + 大盘同步强趋势 + 个股强度 ≥ 大盘强度。这是整个 A 股生态里最理想的交易标的形态：赚 β 的钱、也赚 α 的钱。

## 四、TET 四件套组合使用：一套最简决策树

把四个指标串起来就是一棵决策树：

```
Step 1. JTS 是不是 > 0？
         ├─ 不是（背离 / 同跌）→ 结束，不做多
         └─ 是 → Step 2
Step 2. TI 是不是 >= 1.0？
         ├─ 不是 → 观察，等待情绪平稳
         └─ 是 → Step 3
Step 3. EI 是不是 <= 0.3？（别是刚涨完一波的亢奋顶）
         ├─ 不是（EI > 0.3 超买）→ 等情绪回落
         └─ 是 → 建仓 / 加仓

退出条件任意命中一条即减仓：
- ATS 跌回 0 或转负
- TI 连续 3 日 < 0.5
- JTS 翻为 0 或负（方向背离或跑输大盘）
```

这套决策树刻意避开了"具体价位"和"精确仓位百分比"——因为那些依赖每个人的资金规模、风险偏好和持仓组合。**TET 只负责回答"现在是不是一个合适窗口"，至于买多少、止损放哪，由你自己的交易系统决定。**

## 五、和常见指标的对比

| 维度 | MACD / RSI / KDJ | Bollinger Bands | TET 指标 |
|---|---|---|---|
| 是否区分"趋势 vs 情绪" | 否 | 否 | **是**（ATS 与 EI 显式分离） |
| 是否纳入大盘联动 | 否 | 否 | **是**（JTS） |
| 是否显式声明"不做空" | 否 | 否 | **是**（`TI ≤ −1` 仅观望） |
| 噪声过滤 | 低通滤波 | 标准差 | **锚定日** |
| 适合市场 | 全市场 | 全市场 | **A 股**（含涨跌停 + 个股散户结构） |

**核心差异**：MACD 之类的传统指标，是基于"价格是信息的有效载体"的有效市场假说设计的——它假设所有波动都是信号。但 A 股是一个散户占比极高、情绪波动常常盖过基本面的市场；**把情绪从趋势里剥离出来，比再叠加一层 MA 滤波有用得多**。

## 七、常见问题 FAQ

**Q1：TET 是预测指标吗？能预测涨跌吗？**
A：**不是**。TET 是状态描述型指标，它回答的是「当下这支股票处于什么状态」，而不是「明天涨不涨」。短期涨跌几乎不可被稳定预测，这已经是数十年学术界与实战界的共识。用 TET 的正确姿势是**筛选窗口**，不是**预测点位**。

**Q2：TI ≤ −1 为什么不能做空？**
A：两个原因。**一是工具层面**：A 股散户不方便做空（融券标的有限、成本高、强平风险大）；**二是市场结构层面**：在"趋势走弱但情绪仍热"的背景下，A 股往往会有一波「反身性反弹」（情绪推动下的反弹），这时候做空爆仓概率很高。所以 TET 的 `TI ≤ −1` 明确定义为**观望信号**，而不是做空信号。

**Q3：ATS 的"锚定日"是怎么选出来的？**
A：在每段窗口内找出**换手率 + 振幅 + 涨跌幅绝对值**都处于同期中位数附近的交易日。这些日子没有明显的利好利空刺激，价格更多反映的是"本位趋势"。具体实现可以参考 [多智能体 AI 如何分析一支股票？TradingAgents 架构完全解析](https://nbstockai.com/guide/multi-agent-stock) 里的数据处理章节。

**Q4：JTS 为什么选沪深 300 做基准，不是上证指数？**
A：沪深 300 成分股流动性更好、权重分布更均匀，β 的估计更干净；上证指数受银行 / 石油石化等权重股扭曲严重，不适合做个股强度的相对基准。同样道理，创业板的股票也建议额外看一次以创业板指为基准的 JTS。

**Q5：TET 在震荡市里好用吗？**
A：震荡市里 ATS 普遍接近 0，这时候 TI 很难突破 1.0 —— 这恰恰是 TET 想告诉你的："**现在不是趋势市，不要用趋势策略硬做**"。TET 不是万能策略，它会在震荡市里安静地给出"未触发"信号，帮你省下踏空踏错的摩擦成本。

**Q6：TET 可以自己实现吗？**
A：可以。核心思路：① 按窗口识别锚定日；② 在锚定日序列上做鲁棒回归得到 ATS；③ 独立计算 EI（RSI 归一化 + 换手率偏离度融合）；④ ATS − EI 得到 TI；⑤ 个股 ATS 与沪深 300 ATS 按规则合成 JTS。完整工程实现细节，可以看我们团队写的 [多智能体 AI 架构解析](https://nbstockai.com/guide/multi-agent-stock) 第四节。

## 八、小结

TET 指标体系的价值，不在于给你一个"买入信号"，而在于给你一套**不被情绪绑架的决策语言**：

- **ATS** 告诉你真实趋势；
- **EI** 告诉你市场情绪在哪；
- **TI** 把这两件事合成一个择时分；
- **JTS** 提醒你"大盘是不是在帮忙"。

这四个指标加起来不到一屏就能看完，但它背后替你做了三件事：**过滤了情绪噪声、分离了趋势与情绪、纳入了大盘联动**。对于大部分不具备高频量化基础设施的中小投资者来说，这已经比"每天盯 K 线 + 看研报 + 刷股吧"要高效得多。
