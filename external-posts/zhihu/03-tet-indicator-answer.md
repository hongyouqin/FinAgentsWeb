## 版本 A：发到问题 #3「量化择时在个人账户中有实际意义吗？」

### 钩子首段（替换原首段）

---

先说结论：**有实际意义，但前提是你得先搞清楚"择时"不是在赌方向，而是在找窗口**。

大多数散户理解的择时 = "我觉得明天要涨 / 我觉得下周要跌"——这不叫择时，这叫赌博。真正的量化择时回答的是：**"现在是不是一个适合我做多的时间窗口？"** 它不猜方向，只核对信号。

我做了约两年半的 A 股策略，自建过一些回测框架，也帮量化团队调过参。看了太多散户朋友的交易日志，一个非常普遍的现象是：

> **基本面看对、方向看对，却因为被当天的情绪带偏，要么过早离场、要么高位追涨。最后复盘时往往发现，错的不是判断，是择时。**

下面从头说一下我这两年沉淀下来的认知，以及一个叫 **TET** 的三维指标体系——它专门设计来解决"择时变追涨"的问题。这套东西在网上资料不多，但我个人用下来最满意。

## 版本 B：发到问题 #4「MACD 金叉死叉后还是亏钱」

### 钩子首段（替换原首段）

---

先回答题主标题的后半句：**这些技术指标有用，但 MACD 金叉死叉在 A 股里有一个致命缺陷——它把"情绪导致的上涨"当成了"趋势确认的信号"**。你按金叉买入的时点，往往是情绪最高、短线最接近回调的那一天。

这不是你学艺不精，是指标设计假设和 A 股市场结构不匹配。

我做 A 股策略约两年半，自建过回测框架，看过太多散户朋友按金叉买入、按死叉割肉，然后在下一个金叉时点位已经比上次割肉价高了 8%。一个非常普遍的现象是：

> **技术指标给的信号是对的——按它的规则确实该买/该卖——但它的规则在 A 股这种高情绪市场里，天然会把情绪噪声当成趋势信号**。

下面说一套我这两年沉淀下来的替代思路，叫 **TET** 三维指标体系——专门为 A 股情绪结构设计的择时方案。这套东西在网上资料不多，但我个人用下来最满意。

## 一、散户的问题不是"不会选股"，是"择时被情绪绑架"

我见过至少几十份散户朋友发给我的交易记录，最常见的场景：

- **基本面研究得很清楚**，确定这是支好公司；
- **买入时机也蒙对了**，至少是在合理区间里；
- 然后中间某一天，**大盘一根长阴 / 讨论区传"主力砸盘" / 账户浮亏 3%**，扛不住就割肉了；
- 割掉之后股价涨回来，甚至突破了新高。

这不是选股问题。这是**情绪管理 + 择时信号**的问题。

传统技术指标（MACD、RSI、KDJ、布林带）有一个共同的设计假设：**价格数据里所有波动都是信号**。这个假设在纯机构市场（美股大盘股、日经权重股）勉强成立，但在 A 股——这个**散户占比 60% 上下、涨跌停板制度、新闻情绪溢出严重**的市场——这个假设本身就有问题。

涨停当天 MA 上移，不代表趋势更强；它可能只是一次情绪推升的散户追涨。**如果你的指标没法区分"趋势信号"和"情绪信号"，那它在 A 股上给出的入场点就会被情绪带偏**。

## 二、TET 是一个尝试："先拆、再合"

我想说的这套指标叫 **TET = Trend · Emotion · Timing**。它的设计思路可以用一句话概括：

> **先在算法层面把"趋势信号"和"情绪信号"拆开算，再通过一个减法合成择时分。**

具体拆成 4 个指标：

### 1. 锚定趋势 ATS（Anchored-Trend-Score）

**值域 `[-1, 1]`。核心思路：只在"情绪平稳的交易日"上算趋势**。

怎么判定"情绪平稳"？在任意窗口内，把**换手率偏离度 + 振幅偏离度 + 涨跌幅绝对值**三个维度都处于同期中位数附近的交易日挑出来，叫"锚定日"。

然后只在这些锚定日的收盘价序列上做**鲁棒线性回归**，归一化到 `[-1, 1]`。

**这样做的好处**：涨停日、巨阴日、异动日这些情绪最大的交易日**会被自动排除在外**。ATS 不会被一根涨停骗到、也不会被一根长阴吓到。

### 2. 情绪指数 EI（Emotion-Index）

**值域 `[-1, 1]`。关键设计：不用价格数据**，改用换手率偏离度、振幅、RSI 这些"价格之外的情绪代理变量"算出来的情绪标尺。

- `EI ≤ -0.3`：情绪低迷（别人恐惧我贪婪的典型入场区）
- `-0.3 ~ 0.3`：情绪平稳（最适合做决策的窗口）
- `EI ≥ 0.3`：情绪亢奋（即使趋势仍强也要警惕短期回调）

**为什么 EI 不用价格**？因为如果 EI 和 ATS 共用数据源，减法 `ATS - EI` 就只是对同一份数据做两次变换，没有任何信息增益。**让 EI 独立信源，减法才有意义**。

### 3. 择时信号 TI（Timing-Indicator）

公式：

```
TI = ATS − EI
```

值域 `[-2, 2]`。

这个公式朴素到让人不敢相信它有用，但它把"**趋势向上 + 情绪未爆发**"这种最理想的入场形态显式赋了高分：

- `TI ≥ 1.0`：考虑做多（趋势强 + 情绪冷的理想窗口）
- `0.5 ≤ TI < 1.0`：偏多观察
- `-1.0 < TI < 0.5`：未触发
- `TI ≤ -1.0`：趋势不明 / 观望——**不做空**

为什么 `TI ≤ -1` 不做空？两个原因：**A 股散户做空工具有限 + 趋势走弱叠加情绪仍热时，A 股很容易出现反身性反弹，做空容易爆仓**。所以这个指标被设计成**不对称**的——只给做多信号，不给做空信号。这是对 A 股市场结构的尊重，不是指标设计的缺陷。

### 4. 联合趋势 JTS（Joint Trend Score）

**把大盘联动加进来**。规则很简单：

- **个股 ATS 和沪深 300 ATS 同向**（都涨 / 都跌）→ **取两者里更弱的那一方打分**
- **方向相反** → **直接判 0 分**（A 股"方向背离"通常撑不过 2~3 周）
- **越接近 +1 越理想**：个股顺着大盘涨势且强于大盘

这个指标替你回答一个非常关键的问题：**大盘现在是在帮你的忙，还是在拖你的后腿？**

## 三、怎么用？一棵最简决策树

我自己是这么用的，你可以拿去参考：

```
1. JTS > 0？ 否 → 不做多
            是 → 看下一步
2. TI >= 1.0？ 否 → 观察
              是 → 看下一步
3. EI <= 0.3？ 否（亢奋顶）→ 等情绪回落
              是 → 建仓

任意一条命中就减仓：
- ATS 跌破 0
- TI 连续 3 日 < 0.5
- JTS 翻 0 或负
```

**注意这棵树里没有"具体价位"和"具体仓位百分比"**——那些依赖你自己的资金规模和风险偏好。TET 只负责回答"**现在是不是一个合适的窗口**"，至于买多少、止损放哪里，是你交易系统的事。

## 四、和 MACD / RSI 对比最明显的差异

我做过一个自测：同样一支股票，用同样的一段时间，分别标注 MACD 金叉日和 TI >= 1.0 的日子：

- **MACD 金叉日** 在"连涨 5 天后的涨停日"密集出现——这些往往是短线顶部；
- **TI >= 1.0** 的日子 更多出现在"震荡整理 2 周后、刚刚开始温和放量"的窗口里——这些更接近真正的趋势起点。

直观看完后你会理解一件事：**不是 MACD 没用，是 MACD 把情绪信号当成了趋势信号**。

## 五、它的局限

最后说几个诚实的短板：

1. **震荡市里 TET 基本不触发**——ATS 接近 0、TI 很难到 1.0。这不是 bug，这是 feature（TET 会安静地告诉你"现在不是趋势市"）。但如果你原本期待"震荡市里也能抓短波段"，TET 给不了你这个能力。
2. **TET 不是预测指标**。它只能描述"当下的状态"，不能预测下周涨跌。用 TET 的正确姿势是**筛选窗口**，不是**预测点位**。
3. **数据口径敏感**。锚定日阈值、情绪因子权重都需要一定的调参。建议用近 2-3 年、涵盖牛熊不同阶段的数据做一次稳定性测试。
