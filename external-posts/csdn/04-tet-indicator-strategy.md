## 写在前面

> 本文是一篇量化策略学习笔记，不是推广软文、也不构成投资建议。文中涉及的阈值、公式与口径，对应的是一个作者亲自参与过的 A 股策略回测框架的当前版本。如果你是量化策略方向的开发者 / 研究员，或者做过 A 股散户账户交易的产品经理，本文或许对你有用。

做 A 股策略有一个非常绕不开的槽点：**大部分经典技术指标，都是在"所有价格波动都是信号"的假设下设计的**。MACD、RSI、KDJ、布林带，本质上都把价格数据整体塞进一个滤波器里，然后产出一个信号。但 A 股是一个**情绪占比极高**的市场——涨停当天 MA 上移，不代表趋势更强，可能只是一次散户追涨的情绪爆发。

这就是我这两年一直在思考的问题：**能不能在算指标之前，先把"价格中的趋势信息"和"价格中的情绪信息"显式分开？**

TET 指标体系就是沿着这个思路设计的。TET = Trend · Emotion · Timing。本文把它的设计动机、公式、阈值、以及和传统指标的差异逐层拆开讲一遍。

## 一、设计动机：有效市场假说在 A 股的局限

有效市场假说（EMH）认为价格已经反映所有可得信息，所以所有波动都是信号。但 A 股的现实是：

1. **散户交易占比远高于机构**（根据历年证交所交易结构统计，散户成交额占比长期在 60% 上下）；
2. **涨跌停板制度**导致价格信息被阶段性截断；
3. **新闻 / 研报 / 社交媒体**的情绪溢出，使短期价格被推离"基本面隐含价格"。

这三条结构性事实导致：**用一个单一滤波器把价格序列变成信号，天然会把情绪噪声当成趋势信号处理**。我们需要的不是"再调一个 EMA 平滑参数"，而是**从数据口径层面把情绪剥出去**。

## 二、ATS（Anchored-Trend-Score）：在情绪最平稳的日子上算趋势

### 2.1 核心思路：锚定日

定义一个交易日集合 `Anchor(t)`：它是窗口 `[t-N, t]` 内，**换手率偏离度 + 振幅偏离度 + 涨跌幅绝对值**三者都处于同窗口中位数附近的交易日。

用自然语言翻译：**那些今天没发生太多事、价格静静地反映"本位趋势"的交易日**。

```python
# 伪代码示意（非最终实现，仅表达思路）
def anchor_days(df, window=60):
    sub = df.tail(window).copy()
    sub['turn_dev']  = (sub['turnover'] - sub['turnover'].median()).abs()
    sub['amp_dev']   = (sub['amplitude'] - sub['amplitude'].median()).abs()
    sub['chg_abs']   = sub['pct_change'].abs()
    # 三个维度都在该窗口的下半分位数内
    mask = (
        (sub['turn_dev']  <= sub['turn_dev'].quantile(0.6)) &
        (sub['amp_dev']   <= sub['amp_dev'].quantile(0.6))  &
        (sub['chg_abs']   <= sub['chg_abs'].quantile(0.6))
    )
    return sub[mask]
```

这些日子被我们称作"锚定日"。

### 2.2 在锚定日上做鲁棒回归

只在锚定日的 `(交易序号, 收盘价)` 上做一次**Huber 鲁棒线性回归**（普通 OLS 对 outlier 太敏感），然后把回归斜率归一化到 `[-1, 1]`：

```
slope_raw = HuberRegressor().fit(anchor.index, anchor.close).coef_[0]
ATS = tanh(slope_raw / sigma)    # 归一化到 (-1, 1)
```

其中 `sigma` 是同期样本的价格尺度，用于把不同价格量级的股票压到可比区间。

### 2.3 为什么比 MACD 更稳？

同样一支"连涨 5 天后涨停"的股票：

- **MACD** 当天给出一个极强的 DIF 上穿，第二天就有人跟进追涨；
- **ATS** 把"连涨 5 天"识别为非锚定日（涨幅绝对值偏大）、把"涨停日"识别为非锚定日（振幅偏大），只在"接下来 2-3 天情绪回归的平稳日"继续拟合。**如果股价回归，ATS 会下修；如果情绪平稳后价格继续稳健上移，ATS 才会真正上调**。

这让 ATS 在"连涨末端 + 见顶回调"这种最容易让散户高位买入的形态上，表现出了肉眼可见的克制。

## 三、EI（Emotion-Index）：独立的情绪标尺

### 3.1 为什么 EI 要和 ATS 不共用数据源

如果 EI 也用价格序列，它必然和 ATS 线性相关——减法 `ATS − EI` 就只是对同一数据的两次变换，没有信息增益。

所以我们让 EI **显式使用"价格之外"的情绪信号**：

- **RSI 归一化**：捕捉短周期超买超卖；
- **换手率相对偏离度**：衡量"市场对今天的价格多激动"；
- **振幅 / ATR**：衡量"波动的剧烈度"；
- （可选）**新闻情感得分、龙虎榜净流入、分时成交结构**：更高频的情绪代理变量。

三到五个因子做截面标准化后加权平均，再 tanh 到 `[-1, 1]`：

```python
ei_raw = (w1 * rsi_std + w2 * turn_dev_std + w3 * atr_std + ...) / sum(weights)
EI = tanh(ei_raw)
```

### 3.2 阈值

- `EI ≤ -0.3`：情绪低迷 / 深度超卖（历史上 "别人恐惧我贪婪" 的典型入场区）
- `-0.3 < EI < 0.3`：情绪平稳（最适合加减仓的决策窗口）
- `EI ≥ 0.3`：情绪亢奋 / 超买（即使趋势仍强也要警惕短期回调）

## 四、TI（Timing-Indicator）：一个减法解释一切

```
TI = ATS − EI
```

这个公式看起来朴素，但它的业务语义非常干净：

| 形态 | ATS | EI | TI | 含义 |
|---|---|---|---|---|
| 理想做多窗口 | 高 | 低 | **高** | 趋势稳 + 情绪未爆发 |
| 情绪驱动的上涨 | 低 | 高 | 低 | 没有真趋势，只是情绪 |
| 趋势向下 + 恐慌 | 低 | 低 | 中等 | 超跌反弹窗口（但不该做空） |
| 无趋势震荡 | 0 | 0 | 0 | 观望 |

一个减法，就把"趋势稳 + 情绪未爆发"这种最值钱的形态显式赋高分。

### 关于 `TI ≤ −1.0` 为什么定义为"观望"而不是"做空"

两个原因，缺一不可：

1. **工具层面**：A 股散户做空极其不便（融券标的有限、T+0 紧平仓风险高）；
2. **市场结构层面**：在"趋势走弱但情绪还热"的组合下，A 股非常容易出现**反身性反弹**——情绪推动的反弹往往让做空仓位快速被击穿。

所以我们在指标设计阶段就做了一个**不对称选择**：负值区域一律归为观望信号，只有正值突破 1.0 才作为入场信号。这是对 A 股市场结构的尊重。

## 五、JTS（Joint Trend Score）：把大盘 β 显式加进来

单看个股是不够的。一支 ATS 向上的股票，在大盘系统性下跌时你大概率还是会亏钱。这就是经典的"**β 拖累**"。

JTS 的计算规则：

```
个股 ATS = a, 大盘 ATS = b

if sign(a) == sign(b):
    JTS = sign(a) * min(|a|, |b|)      # 同向取弱
else:
    JTS = 0                             # 方向相反直接 0 分
```

翻译：

- **同向取弱**：个股很强、大盘很弱 → 按大盘打分（强度被大盘拖后腿）；
- **反向判 0**：承认 A 股"方向背离"结构的不稳定性，直接归零。

大盘基准默认选**沪深 300**而不是上证指数：沪深 300 成分股流动性更好、权重分布更均匀，β 估计更干净；上证指数被银行 / 石油石化权重股扭曲严重。

## 六、四件套组合使用：一套最简决策树

```
Step 1. JTS > 0 ?
         No → 结束，不做多
         Yes → Step 2

Step 2. TI >= 1.0 ?
         No → 观察
         Yes → Step 3

Step 3. EI <= 0.3 ?   (避开亢奋顶)
         No → 等情绪回落
         Yes → 建仓 / 加仓

退出（任意命中即减仓）：
- ATS 跌回 0 或转负
- TI 连续 3 日 < 0.5
- JTS 翻 0 或负
```

这棵树刻意**不指定具体价位和仓位百分比**——那些依赖每个人的资金规模、风险偏好和已有持仓。TET 只负责回答"**现在是不是一个合适窗口**"。

## 七、和常见技术指标的对比

| 维度 | MACD / RSI / KDJ | Bollinger Bands | **TET 指标** |
|---|---|---|---|
| 趋势 vs 情绪是否显式分离 | 否 | 否 | **是** |
| 大盘联动 | 否 | 否 | **JTS** |
| 涨停 / 巨阴日处理 | 当普通数据 | 当普通数据 | **按非锚定日跳过** |
| 不做空的价值观 | 无 | 无 | **明确定义** |
| 适合市场 | 全市场 | 全市场 | **A 股特化** |

核心差异总结一句话：**传统技术指标默认"所有波动都是信号"，TET 默认"大部分日内波动是情绪、只有锚定日的方向才是趋势"**。这两种假设在 A 股这种高情绪市场里，给出的信号质量会拉开非常明显的差距。

## 八、小结

写到这里，TET 的三件套 + 一件衍生品就讲完了：

- **ATS** 告诉你真实趋势（去噪）；
- **EI** 告诉你市场情绪（独立信源）；
- **TI** 把趋势和情绪一减，得到择时分；
- **JTS** 把大盘 β 显式纳入。

我自己把这套指标用下来最大的感受是：**它不会帮你在顶部精准卖出、也不会帮你在底部精准抄底**（这些任务本来也没有任何指标能稳定完成），但它**在震荡市里会老老实实地给你"未触发"信号，帮你避开高频踏空 / 踏错的手续费摩擦**。
